# یادآور من (nsa)

**یادآور من (NSA)** یک اپلیکیشن اندرویدی برای ثبت و یادآوری هوشمند کارها، قسط‌ها، بدهی‌ها و کارهای دوره‌ای است؛ برای مثال یادآوری تعویض روغن خودرو، پرداخت قسط، سررسید بدهی یا هر کاری که نیاز به یادآوری دارد.

هدف پروژه، ارائه یک ابزار ساده، کاربردی و قابل‌اعتماد برای استفاده عموم است.

## وضعیت پروژه

### فاز ۱ — هسته اصلی

* افزودن یادآوری متنی
* تعیین تاریخ و ساعت
* تکرار یادآوری به صورت روزانه، هفتگی، ماهانه و سالانه
* دسته‌بندی دلخواه یادآوری‌ها
* اعلان دقیق با `AlarmManager`
* کارکرد یادآوری حتی در صورت بسته بودن برنامه
* بازبرنامه‌ریزی خودکار یادآوری‌ها پس از راه‌اندازی مجدد گوشی
* پشتیبانی از شرایط بهینه‌سازی باتری در گوشی‌های مختلف
* زیرساخت اطلاعات مالی در مدل داده شامل مبلغ و طرف حساب
* ورودی صوتی (Speech-to-Text)
* امکان Snooze
* پشتیبانی از یادآوری‌های چندمرحله‌ای

### فاز ۲ — توسعه قابلیت‌ها

* امکانات تکمیلی مدیریت مالی
* ثبت و مدیریت پرداخت‌های جزئی
* تشخیص طبیعی تاریخ و زمان
* امکان افزودن پیوست و تصویر
* بهبود تجربه کاربری و هوشمندی یادآوری‌ها

### فازهای آینده

قابلیت‌های جدید بر اساس نیاز کاربران و روند توسعه پروژه اضافه خواهند شد.

> **نکته:** در حال حاضر برنامه وابستگی به سرویس ابری یا بکاپ ابری ندارد و اطلاعات اصلی برنامه به صورت محلی روی دستگاه کاربر نگهداری می‌شوند. قابلیت بکاپ ابری در اولویت فعلی پروژه نیست.

## حریم خصوصی

NSA با رویکرد **Local-first** توسعه داده می‌شود.

اطلاعات اصلی مربوط به یادآوری‌ها و داده‌های برنامه در نسخه فعلی به صورت محلی روی دستگاه کاربر نگهداری می‌شوند و پروژه در وضعیت فعلی برای عملکرد اصلی خود به حساب کاربری یا سرویس ابری نیاز ندارد.

دسترسی‌های موردنیاز برنامه، متناسب با قابلیت‌های آن و با هدف ارائه امکاناتی مانند اعلان و یادآوری استفاده می‌شوند.

## معماری فنی

* **زبان:** Kotlin
* **UI:** Jetpack Compose + Material 3
* **معماری:** MVVM (`ReminderViewModel` + `StateFlow`)
* **ذخیره‌سازی محلی:** Room Database
* **زمان‌بندی اعلان:** `AlarmManager.setExactAndAllowWhileIdle`
* **حداقل نسخه اندروید:** API 26 (Android 8.0)

برای یادآوری‌های دقیق زمانی از `AlarmManager` استفاده شده است و این بخش عمداً به جای `WorkManager` طراحی شده است.

## راه‌اندازی محیط توسعه

### پیش‌نیازها

* JDK 17
* Android SDK Command Line Tools
* Gradle 8.9

برای توسعه پروژه الزاماً به نصب کامل Android Studio نیاز نیست.

```bash
git clone https://github.com/naderii/nsa.git
cd nsa
```

### نکته مهم درباره JDK

فایل `gradle.properties` مسیر JDK 17 را به صورت مستقیم پین کرده است تا پروژه مستقل از نسخه پیش‌فرض Java سیستم باشد.

در صورت متفاوت بودن مسیر JDK 17 روی سیستم، مقدار مربوطه را در `gradle.properties` اصلاح کنید.

برای مشاهده مسیرهای Java:

```bash
update-alternatives --list java
```

### تولید Gradle Wrapper

در صورت نیاز:

```bash
gradle wrapper --gradle-version 8.9 --distribution-type bin
```

### بیلد

```bash
./gradlew assembleDebug
```

فایل APK در مسیر زیر ایجاد می‌شود:

```text
app/build/outputs/apk/debug/
```

برای نصب مستقیم روی گوشی متصل‌شده با USB:

```bash
./gradlew installDebug
```
